# Atelier Assets

The two wallpapers in `assets/wallpapers/` are AI-assisted fan concept scenes
inspired by Dusk's painting-room and painted-world setting. They are not
official artwork or a verified reconstruction of a canonical room layout.
The existing Dusk portrait remains unchanged.

- Motion: https://github.com/motiondivision/motion (MIT; `assets/Motion-LICENSE.txt`).
- Smiley Sans: https://github.com/atelier-anchor/smiley-sans (OFL; `assets/fonts/Smiley-LICENSE.txt`).
- LXGW WenKai: https://github.com/lxgw/LxgwWenKai (OFL; `assets/fonts/WenKai-LICENSE.txt`).
- Lora: https://github.com/cyrealtype/Lora-Cyrillic (OFL; `assets/fonts/Lora-LICENSE.txt`).

These assets are bundled locally for offline use. There is no runtime font CDN.
Wallpaper uploads and layout preferences are device-local. Courses, plans,
vocabulary progress and rollback dates continue to use the existing shared model.
No demo records or preview storage keys are imported.
